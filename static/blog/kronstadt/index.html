The reported edit

Yle reported on 17 August 2026 that Yandex Maps covered a missile battery near Kronstadt by copying forest from elsewhere in the same satellite image. This analysis is based on that story. Read the Yle report.

The same texture appears twice, shifted. Tie-point matching looks for repeated SIFT-style correspondences that share one translation. Those repeated patterns are drawn as candidate box pairs. A box pair is a candidate you can show or hide in the list.

Detector output

VeriSat’s AI detectors did not pick up this forgery. The edit does not come from a generative model. It is a simple hand-crafted manipulation: pixels copied from one place in the image to another.

Tie-point boxes

A tie-point algorithm was used instead, to see the repeated patterns. Tie points are correspondences that share one translation, and that shared shift is how the repeated forest patch was found. The interactive demo shows that result: the box overlay you can toggle on the main image.

Embeddings of similar features
